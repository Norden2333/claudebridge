Claude 文件连接

一步步接好文件夹

按顺序完成设置；本机、Cowork 设备和当前对话分别检查。

    验证本机文件能力

    读取验证只检查目录，不读取文件正文。读写验证仅新建随机命名的临时测试文件，校验后清理自己的文件，不修改已有文件；若测试文件被外部修改则保留并提示。不会调用模型。

    在 Claude 里完成最后一步

    Chat（推荐）：打开或刷新 Claude 网页，让它用文件连接工具列出 .。小窗会区分网页桥握手和本页实际工具调用。

    Cowork（实验性）：先启用 Remote Desktop Commander 连接器并完成设备验证，再让当前对话列目录。设备在线不代表当前对话可用；如果操作显示完成却没有结果正文，不要重做文件操作；让 Claude 按原调用编号查询已保留回执。短时网络中断会自动补发结果，超过恢复期限仍未确认时，在文件工作台核对。

    本页不会发送聊天消息，也不会自动读取文件正文。

    本机程序没连上？

    Windows 完整包已包含 Node.js，不用另装。先运行“安装Claude文件连接.exe”，再在 Chrome 加载安装目录里的 extension。只有源码包和 macOS/Linux 才需另备 Node.js 22 或更新版。安装目录、Node 路径移动后可能失效；不用先卸载或反复重装。

    Windows 推荐入口：安装Claude文件连接.exe。安装-Windows.cmd 是备用入口，不用两个都运行。macOS：安装-macOS.command；Linux：install-macos-linux.sh。

    这是首次设置引导，不会自行安装程序、切换代理或开启读写权限。

    确认版本与旧版

    安装本机程序和加载浏览器扩展是两步。Chrome 的“重新加载”只重读原目录，不会把旧版 1.0 自动换成新版。更新后版本应与本机程序一致。
    若装过“Claude 文件夹自动连接 1.0”或原 claudeFS，先停用同类旧连接，保留以便切回。不要停用其他无关扩展；本程序不会自动卸载它们。
    

    以后更新
    Windows可双击新包的“更新与切回-Windows.cmd”；macOS运行“更新与切回-macOS.command”；Linux运行 update-or-rollback.sh。也可在关闭全部 Claude 标签页、设置及工作台后，从解压的新包运行 node companion/install.mjs --update。完整性、身份和数据兼容检查通过才更新。设置、登录、参考保护及小窗偏好保留；额外文件不覆盖。更新完成后在 Chrome 扩展页重新加载扩展，再刷新 Claude。
    需要切回时使用更新结果中的编号：在终端运行 node companion/install.mjs --rollback --backup 并在后面追加该编号。代码后来被修改时不会强行覆盖。此页面不会自动执行更新。
    

    按现象查问题
    版本仍是旧的
    “重新加载”只重读原目录。停用同类旧连接，再加载新安装目录里的 extension；不要停用其他无关扩展。
    已连接却不能使用
    本机连接、Cowork 设备在线、当前对话工具验证是三件事。当前对话需启用连接器并验证一次。
    文件没有自动保存
    卡片未识别不等于保存成功。可先用原下载按钮；需要复制到工作目录时再开启备用下载保存。
    记录很多但找不到新增文件
    操作记录不是文件副本。工作台按完整路径归并并分别显示文件数和操作数。
    点击打开没有窗口
    请求不代表系统已显示窗口。使用复制路径或打开工作文件夹的备用入口。
    保存后要不要选版本
    日常自动保存直接更新原文件，不备份、不另存、不弹版本选择；相同内容跳过。
    如何升级与切回
    解压新包不会更新现用程序。已有通用版使用更新与切回入口，保留设置和登录；完成后重载扩展。
    结果未知怎么办
    先核对原操作，不重复执行。重连只恢复连接和回执，不重放未知写入。
    支持网页 Chat；Cowork 为实验性。暂不支持 Claude Code、CLI 和 Remote Control。
